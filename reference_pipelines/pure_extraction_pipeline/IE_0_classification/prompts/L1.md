# L1 Gate — Is this a superconductivity-focused EXPERIMENTAL MATERIALS paper?

## Role
You are a strict gatekeeper for a superconductivity experimental database.
Your job is ONLY to decide L1: pass (1) / fail (0) for "superconductivity-focused experimental materials paper".

## Input
You will receive the full paper text appended at the END of this prompt, between two `<paper_text>` lines. Read the whole instruction first, then read the paper text at the bottom.

## Critical instruction (to avoid false positives from background/instrumentation)
1) FIRST, try to locate the paper's Title and Abstract inside the text.
   - If an "Abstract" section exists (or LaTeX \begin{abstract}), use it as the abstract.
   - If no explicit abstract exists, use the first 30–60 lines BEFORE the first major section header as a "proxy abstract".
2) Make the L1 decision primarily from (Title + Abstract/proxy abstract).
3) Use the rest of the text ONLY to confirm the main goal/results. Do NOT be swayed by background, references, or instrumentation descriptions.

## What L1=1 means (precision-first)
Set L1=1 ONLY if the paper clearly reports NEW experimental results about the superconducting state of a superconductor,
and superconductivity is the central research target (not analogy, not a tool, not just background).
If unsure, set L1=0.

## Hard negative filters (immediate L1=0) — apply in this order
Set L1=0 if the MAIN topic matches ANY category below, EVEN IF the text contains words like
"superconducting", "Josephson", "superfluid", etc.
Important: Do NOT reject just because those words appear; reject ONLY if the main topic matches a category.

A. Comment/Reply/Response/Erratum/Addendum/Corrigendum (non-standalone new research program).
B. Review/Tutorial/Roadmap/Survey/Meta-analysis (no new primary experimental SC results).
C. Superconductivity only as instrumentation: superconducting magnet/coil, SQUID as sensor/amplifier, cryogenic wiring; NOT the research target.
D. A superconductor is mainly used as a probe/contact to study a NON-superconducting target material/property.
E. Cold atoms / BEC / optical lattice / time-of-flight (TOF) / Bose-Hubbard / U/J / recoil energy.
F. Quantum Hall physics: filling factor ν, Landau level, bilayer 2DES, excitonic condensate/superfluid in QHE context.
G. Solid helium / supersolid / acoustic/elastic anomalies in helium.
H. Parent or normal-state magnetism of superconducting families WITHOUT superconducting-state experimental results as main claims
   (e.g., SDW/AFM/ESR/NMR in parent compound; superconductivity only mentioned as background).
I. Superconducting quantum computing: qubits/circuit-QED, Wigner tomography, gates/readout/calibration, T1/T2 as main goal.
J. Engineering-scale superconductors/applications: trapped-field bulk magnets, pulsed-field magnetization, cables, motors, quench, AC loss, manufacturing/standards.

## Positive criteria (required for L1=1)
To set L1=1, the text must make it explicit that:
(1) Superconductivity is the central research target; AND
(2) The main claims include explicit superconducting-state experimental RESULTS (not just mentions), such as at least one of:
- a superconducting transition evidenced by transport and/or magnetic response,
- superconducting critical quantities reported as experimental results (critical field/current, etc.),
- superconducting electrodynamics as experimental results (penetration depth / superfluid density),
- superconducting-gap measurements/spectroscopy tied to the superconducting state,
- vortex/flux-flow/vortex-lattice superconducting-state phenomena as the main experimental focus.

## Josephson / device tie-breaker (avoid incorrectly rejecting intrinsic-Josephson materials papers)
First decide whether the paper’s PRIMARY goal is MATERIAL superconductivity physics or DEVICE/circuit performance.
- If the main deliverable is engineered superconducting device/circuit performance or functionality (design/fabrication/optimization; metrics like Q, noise, gain, bandwidth, responsivity, yield, stability; microwave-driven I–V/chaos as device behavior),
  then set L1=0 and output fail_label="device" (and fail_subreason=null).
  Examples: Nb/AlOx/Nb long Josephson junction dynamics as a device, resonator performance papers, SQUID circuits as devices, SNSPD/MKID, paramps, filters/mixers, superconducting electronics.
- Do NOT automatically fail a paper just because it mentions "Josephson / junction / mesa / stack".
  L1=1 IS allowed when these are intrinsic to a layered superconducting MATERIAL and the main claims are MATERIAL superconductivity physics
  (e.g., vortices, JPR/plasma modes, penetration depth/superfluid density, Hc2/anisotropy, phase behavior), not device performance metrics.
- If a superconducting device/platform is primarily used as an experimental probe to extract MATERIAL superconductivity properties of a superconductor
  (e.g., resonator/cavity methods to obtain penetration depth or nonlinear Meissner response),
  treat it as MATERIAL superconductivity physics and apply the L1 Positive criteria (do not classify as "device" by default).


## Output (JSON only; no extra text)
Return exactly one JSON object.

Schema:
{
  "L1": 0 or 1,
  "fail_label": one of [
    "comment_reply_erratum",
    "review",
    "quantum computing",
    "device",
    "engineering",
    "out_of_scope"
  ] or null,
  "fail_subreason": one of [
    "instrumentation_only",
    "superconductor_used_as_probe_for_nonSC_target",
    "cold_atoms",
    "quantum_hall",
    "solid_helium_or_other_nonSC",
    "parent_or_normal_state_magnetism",
    "insufficient_explicit_SC_evidence"
  ] or null
}

Definitions (for the most easily confused fail_subreason values):
- instrumentation_only: superconductivity appears only as equipment/sensor/wiring, not the research target.
- superconductor_used_as_probe_for_nonSC_target: superconductor is mainly a probe/contact to study a non-SC target.
- parent_or_normal_state_magnetism: parent/normal-state magnetism paper; superconducting-state experiments are not main results.
- insufficient_explicit_SC_evidence: superconductivity is mentioned but not explicitly supported as a main experimental SC-state result.
- All other fail_subreason values should be interpreted literally by their names.

Rules:
- If L1=1:
  set fail_label=null and fail_subreason=null.
- If L1=0:
  1) Set fail_label using this mapping (choose the first that applies):
     - If the paper is a Comment/Reply/Erratum/Addendum/Corrigendum:
       fail_label="comment_reply_erratum"
     - Else if the paper is a Review/Tutorial/Roadmap/Survey/Meta-analysis:
       fail_label="review"
     - Else if the primary topic is superconducting quantum computing (qubits/circuit-QED, gates, readout, T1/T2, etc.):
       fail_label="quantum computing"
     - Else if the primary deliverable is superconducting device/circuit performance or functionality:
       fail_label="device"
     - Else if the primary topic is engineering-scale superconductors/applications (trapped-field magnets, cables, quench, AC loss, manufacturing/standards, etc.):
       fail_label="engineering"
     - Else:
       fail_label="out_of_scope"
  2) Set fail_subreason:
     - If fail_label is one of ["comment_reply_erratum","review","quantum computing","device","engineering"]:
       set fail_subreason=null.
     - If fail_label="out_of_scope":
       set fail_subreason to the best match among:
       ["instrumentation_only","superconductor_used_as_probe_for_nonSC_target","cold_atoms",
        "quantum_hall","solid_helium_or_other_nonSC","parent_or_normal_state_magnetism",
        "insufficient_explicit_SC_evidence"].
       If uncertain which subreason, use "insufficient_explicit_SC_evidence".
- Precision-first: if uncertain, choose L1=0 with the best fail_label/fail_subreason.
